# Lifepath Balance Register (living)

Current balance surface for the **outcome-scaling economy** (M22–M24) — the
mechanic where the performing player's skill band modifies what they produce.
Point-in-time audits stay in `BETA8_BALANCE_AUDIT.md`; this file is the living
register and must be updated whenever an `outcome_rule` file changes.

Every number below is shipped data — `data/lifepath/outcome_rule/<skill>.json`
is the source of truth; this table is generated by reading them.

### Config clamps (`config/lifepath/skills.toml`)

`outcome_scaling_enabled` (master) · `outcome_max_failure_chance` .50 ·
`outcome_min_count_mult` .25 · `outcome_max_count_mult` 2.0. Datapack values
outside clamps are clamped at resolve time — hostile packs can't zero-drop the
economy.

## Attribution contract

XP and outcomes always credit the **performing player** — result-slot taker,
anvil user, block breaker, hook owner, killer (shooter for projectiles),
Overgeared hammer-swinger. Full seam table: `docs/ATTRIBUTION.md`.

## Exploit audit

- **Replant/re-mine**: `PlacedBlockTracker.contains()` guard — player-placed
  blocks get no outcome scaling and no XP. Replant-and-reharvest a wheat crop
  still works (the *crop* is natural growth — intended).
- **Automation**: `isAutomation` gates every producer — fake players, clicker
  mods, and non-player damage sources get vanilla drops. Mob-grinder kills
  (lava/fall) carry no player damage source → never scaled.
- **Spam-craft**: low-skill spam is self-defeating — failure chance eats inputs
  and crude output has no market value. XP repetition signatures still apply.
- **Junk fishing**: `junk_upgrade_chance` only exists at expert+; junk itself
  has no value. AFK-fishers are real players but `isAutomation` can't catch a
  real player holding right-click — accepted; the upgrade rate (.25–.60) is
  the tuning knob if it proves abusable.
- **Item-entity merging**: stamped/unstamped same-type stacks can merge and
  the surviving stack keeps its own components — count is conserved, so this
  can launder a `crude` flag onto `masterwork` goods (or vice versa). Cosmetic
  only; no economic exploit since merge never creates count.
- **Overgeared quality bias**: effective tier maps onto native ForgingQuality
  per forge — a failed roll maps to POOR. The bias affects the specific forged
  item only, not the anvil.
